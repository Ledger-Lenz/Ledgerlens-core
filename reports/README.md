# reports/

## Purpose

This directory holds **generated compliance and security reports** produced during CI/CD workflows and local development.

## Contents

### CI-Generated Reports

The following reports are generated automatically by GitHub Actions workflows and local build targets:

#### License Inventory
- **File**: `licenses-python.csv`
- **Generated by**: 
  - CI workflow: [`.github/workflows/license-vuln-scan.yml`](.github/workflows/license-vuln-scan.yml) (on push to main, on PRs touching dependency files, nightly)
  - Local command: `make license`
- **Purpose**: CSV inventory of all Python dependencies and their licenses
- **Audience**: Maintainers, compliance/legal review, CI artifact retention
- **Retention**: 90 days (CI artifacts)

#### Vulnerability Scan Reports (OSV)
- **Files**: `osv-*.txt` (e.g., `osv-python-base.txt`)
- **Generated by**: CI workflow [`.github/workflows/license-vuln-scan.yml`](.github/workflows/license-vuln-scan.yml)
- **Purpose**: Security scan results from [Google OSV Scanner](https://github.com/google/osv-scanner) identifying known CVEs in dependencies
- **Audience**: Maintainers, security review, release gating
- **Retention**: 30 days (CI artifacts)

### On-Demand Reports

The `ComplianceReportGenerator` utility (`detection/compliance_report.py`) can generate HTML/PDF compliance audit reports for individual wallets, but these are typically generated on-demand and saved to caller-specified paths, not this directory.

## Git Behavior

- **`.gitkeep`**: Committed to ensure the directory exists in git clones
- **Generated report files**: Not committed (see `.gitignore` for similar report directories)
- **`.gitignore`**: Currently does not exclude `reports/`, meaning if reports are generated locally they could be accidentally committed. Consider adding `reports/*.csv`, `reports/*.txt`, and `reports/osv-*` patterns if local generation is expected.

## Local Usage

### Generate License Inventory

```bash
make license
# Outputs: reports/licenses-python.csv
```

For details, see the [Makefile](../Makefile) and [CONTRIBUTING.md](../CONTRIBUTING.md).

### Generate OSV Vulnerability Scan

```bash
# Requires osv-scanner: https://github.com/google/osv-scanner
make audit-py
# Outputs: reports/osv-*.txt
```
